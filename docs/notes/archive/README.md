# Archived Experiment Notes

This folder contains historical experiment ledgers. They are kept as evidence
for how conclusions were reached, but they are no longer the first place to look
for the current state of the project.

Start with [`../experiment_synthesis.md`](../experiment_synthesis.md) for the
canonical current interpretation. Then use the archived notes when you need the
older run details, paths, diagnostics, or intermediate reasoning.

Archived notes may include:

- superseded cache paths or output folders
- stale feature-mode semantics
- old normalization or smoothing assumptions
- intermediate conclusions that have since been revised
- negative or inactive experiment lines
