# Manifold and Trajectory Results

New comparisons should use the shared
[experiment report template](../../../docs/experiment_report_template.md), with
related runs grouped in one report and exact runs recorded as rows. Existing
historical summaries are retained as written.

- [Representation accessibility](representation_accessibility.md) records the
  controlled raw-input versus GRU-hidden-state probe.
- [Trajectory analysis status](trajectory_analysis.md) records what the
  exploratory trajectory work can and cannot currently support.

These analyses are exploratory. Their results do not yet establish that a
particular manifold method improves decoding.
