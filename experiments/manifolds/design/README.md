# Manifold analysis design

These analyses are exploratory rather than a fixed transfer-learning method.
They compare raw or minimally transformed neural features with trained decoder
representations, preserve temporal order, and use session-aware controls before
making claims about repeatable geometry.

The current interpretation ladder and next controls are documented in the
[branch README](../README.md); completed analyses are indexed under
[`../results/`](../results/).
