# Cross-Trained Mamba Results

Only implementation, smoke-test evidence, and the qualitative outcome of one
limited BIT-style attempt are canonical in this archive. That run performed
very poorly, but it was not followed by serious tuning, multiple seeds, scaling
comparisons, or a controlled diagnosis. No completed cross-dataset result or
canonical quantitative Mamba benchmark was established.

This branch therefore records an unsuccessful preliminary attempt, not a broad
negative conclusion about Mamba. The retained tests cover the model, data
alignment, and training entry point; output locations are documented in the
branch README and Modal launcher.
