# BIT-Style Results

New comparisons should use the shared
[experiment report template](../../../docs/experiment_report_template.md), with
related runs grouped in one report and exact runs recorded as rows.

There is not yet a canonical completed BIT-style transfer result in this
branch. The implementation and data contracts are ready for controlled Stage 1
and downstream CTC runs; results should be added here as self-contained reports
rather than left only in logs or notebooks.

Earlier generic SSM and masked-reconstruction findings are preserved under
`experiments/archive/` and should not be treated as BIT results.
